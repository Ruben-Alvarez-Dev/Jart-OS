# Documentation

This directory contains the structured public documentation for Jart-OS.

## Sections

### `01-foundations`
Use this section to understand:
- why Jart-OS exists
- what it is
- which principles guide the architecture
- which terms are used consistently across the project

### `02-architecture`
Use this section to understand:
- the tier model
- the metal vs platform boundary
- runtime and service relationships
- the structural logic of the system

### `03-operations`
Use this section to understand:
- how the repository is organized
- how services are registered and deployed
- how the system is operated at a high level

### `04-product`
Use this section to understand:
- use cases
- domain orientation
- roadmap and product direction

## Editorial rule

This `docs/` tree is public-facing and must remain:
- architectural
- generic
- clean
- safe for publication

Private history, raw notes, and sensitive rationale belong in the private workshop repository, not here.
