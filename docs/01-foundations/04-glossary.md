# Glossary

## Canon
The public, curated architectural definition of Jart-OS.

## Workshop
The private space where ideas, drafts, restructuring work, and sensitive historical material are developed before public publication.

## Implementation
A concrete deployment of Jart-OS on a specific machine or environment.

## Metal boundary
The host-level side of the system where machine-coupled capabilities run outside the main platform bubble.

## Platform boundary
The containerized operational space where gateways, services, agents, workflows, interfaces, and control layers run.

## Tier
A numbered architectural layer with a specific responsibility in the system.

## Self-contained service
A deployable service unit that owns its compose file, configuration, persistent data, and logs.

## Canonical repository
The repository that defines the public source of truth for the architecture.
