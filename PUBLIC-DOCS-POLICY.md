# Public Documentation Policy

## Purpose

This repository is public-facing documentation for the Jart-OS architecture.

Its documentation must help a new reader understand:
- what Jart-OS is
- why it exists
- how it is structured
- how it is operated at a high level

## Allowed content

Public documentation may include:
- architectural principles
- tier definitions
- operational conventions
- generic workflows
- sanitized examples
- generic exam-preparation or study-system use cases
- multi-domain platform explanations

## Forbidden content

Public documentation must not include:
- personal identity references
- private professional context
- deployment secrets
- raw historical notes
- sensitive motivations

## Writing rules

- Everything in the repository must be written in English.
- Public docs should explain concepts before implementation detail.
- The repo should present one coherent architectural story.
