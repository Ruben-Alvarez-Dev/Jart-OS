# UI — MCP Apps (Optional)

This directory is for MCP Apps interactive UI components.

Only implement if the backpack's tools benefit from visual interaction
(e.g., memory browser, search results visualization).

## When to use MCP Apps

| Use UI? | Example |
|---------|---------|
| ✅ Yes | Memory browser, search filters, data dashboards |
| ❌ No | Simple CRUD tools, log queries, config management |

## Getting started

```bash
npm init -y
npm install @modelcontextprotocol/ext-apps
```

See: https://github.com/modelcontextprotocol/ext-apps
